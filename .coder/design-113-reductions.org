* Question and existing machinery

The row-only model contract cannot express a parameter-dependent within-sample projection without closing over the data.
The next contract must preserve both the moment mean and the covariance of its contributions, while letting fresh data flow through the compiled solve.
Matching the mean alone does not settle the consumer discrepancy.

* Definitions and invariants

For a fixed nonnegative weight matrix W and dummy design F, let P be the weighted orthogonal projector onto F and M=I-P.
If an instrument z is already projected using the same W, then z' W M y equals z' W y.
This identity also holds for the parameter derivative when F and W do not depend on the parameter.
It does not identify per-row contributions: z_i (M y)_i and z_i y_i generally have different cluster totals and hence different covariance estimates.
With moment-specific observability, the projection must be defined on each coordinate's own exposure, or an explicit common estimation population; a projection under different weights or support does not inherit the identity.
On an unbalanced panel, one product pass followed by one market pass is generally not the joint weighted projection.
An iterative projection needs its own numerical convergence event; fixed iteration count alone is not a convergence certificate.

* Proposed bounded API slice

Retain plain =psi(x_i, theta)= unchanged.
For an explicitly opted-in two-stage model, define a sample reduction =aux(measure, theta)= and a row evaluation using that auxiliary state.
The shared empirical contribution pass computes aux once per evaluation, inside the differentiated objective, and feeds the same residual matrix to moment means, covariance, and Jacobian contributions.
Group IDs are data leaves; declared group counts, model configuration and output labels are static.
Masked rows and zero-weight exposures must be handled before nonlinear operations, preserving the existing NaN discipline.
The one-row label probe must use prepared auxiliary state or explicit labels rather than calling the row method without its prerequisite.
Unsupported measure paths must fail with an explicit contract error; an analytical expectation function needs a declared adapter rather than being silently vmapped as empirical data.

The first implementation should cover the empirical consumer and preserve all three existing measure paths for ordinary models.
A separate acceptance check must generalize the factory's traced-measure manifold path: computing aux correctly does not itself eliminate closure recompilation for fresh manifold datasets.
No covariance or inferential quantity moves into the consumer.

The package empirical expectation, JAX AD and ClusteredCovariance give maximum mean and derivative gaps 9.16e-16 and 6.66e-16, but a covariance-block gap 1.46017.
Projected-residual variances are [0.06489,0.00646], versus raw-residual [1.52506,0.40243].
This demonstrates why an FWL mean identity alone cannot settle a GMM covariance contract.
It is a deterministic counterexample, not a coverage study or an estimator redesign.

* Review boundary and next action

The weighted unbalanced-panel oracle above establishes matching means/derivatives and differing covariance contributions.
Next pin the consumer's intended residual contribution and projection population; this is a statistical contract decision, not an API naming choice.
The proposed API is additive, but its unsupported analytical-model behavior and manifold no-retrace guarantee need to be agreed before calling the complete issue implemented.
Issue 113 remains active with this concrete implementation boundary.
