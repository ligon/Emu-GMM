* Section 1 -- Task, restated (repo vocabulary)

=emu_gmm.studies.replicate= runs =key -> dgp(fold_in(key,r)) -> run -> record()=
and stacks per-rep =FitRecord= s into an =MCRecords= (leading =n_reps= axis).
Layer-2 /summarizers/ reduce that stack (bias/SD, coverage, size/power, tau,
J-calibration), each *excluding-but-counting* non-converged reps. #167 adds two
missing /query/ shapes over the same stack: (a) the *conditional* law -- the
sub-record where a diagnostic event holds (=given=) plus its loud size
(=event_share=); and (b) the *coupled* law -- two CRN-verified arms and their
paired contrasts (=crn_pair=). These lift three hand-rolled readouts in the #130
harness (=scripts/validation/ladder_mc.py=) into the package. The umbrella
(#144) is an =EstimatorLaw= interface; #167 is its narrow, point/tuple-only,
additive first increment.

* Section 4 -- Invariants and assumptions (the landmines)

1. *Event flags are exact-binary.* =record()= casts bool -> float64
   (=types.py:1089-1096=), so =>0.5= == =>0= == ===1= /today/. Guard:
   =test_flags_are_exact_binary=. A future fractional/NaN flag would split =>0.5=
   vs =>0= and silently drift the byte-equal retrofit.
2. *CRN alignment needs same DGP, not just same key.* Master-key equality is
   /necessary but not sufficient/ (the key can't witness the DGP =split= scheme).
   =crn_pair= therefore requires a matching =coupling_id=
   (=MCRecords.coupling_id=, =driver.py:81=) and refuses otherwise unless
   =assert_coupled=True=. Guards: =test_coupling_id_mismatch_refuses=,
   =test_missing_id_refuses_without_assert=.
3. *Masking destroys rep-index alignment.* =given= returns a masked =FitRecord=;
   a conditioned record can never be paired. =crn_pair= rejects non-=MCRecords=
   (=test_rejects_non_mcrecords=). Conditional-paired contrasts go through
   =flips(..., where=event_mask)=, never =pair(given(...))=.
4. *Static fields ride the treedef.* =given= 's =tree_map(lambda l: l[mask], rec)=
   preserves =J_dof= / =param_names= (not leaves). Guard:
   =test_masks_event_and_preserves_static_fields=.
5. *Conditioning on an estimator-internal flag is selection-conditional, NOT
   nominal.* =coverage(given(rec,"binding_ridge"))= is a within-selection
   diagnostic (the event is a function of the same data as =theta_hat= / =se=),
   not a coverage guarantee. *GATED* (#167 Sec. 6.1): =given= emits a
   =SelectionConditionalWarning= on =binding_ridge= / =sigma_meat_indefinite=
   unless =acknowledge_conditional=True=. The blessed use is the within-subset
   nominal-vs-adjusted /p-value/ contrast (=jadj=, which acknowledges). Guard:
   =TestSelectionConditionalGate=.

* Section 6 -- Decisions (resolved questions)

1. *Conditioning hazard exposure (Sec. 4.5). RESOLVED (#167 Sec. 6.1): gate
   (soft).* =given= now emits a =SelectionConditionalWarning= when conditioning
   on an estimator-internal hazard flag (=SELECTION_CONDITIONAL_FLAGS= =
   =binding_ridge=, =sigma_meat_indefinite=), opt-out via
   =acknowledge_conditional=True=. =converged= (the standard exclusion) and
   predicate-form events are not gated; =event_share= (a size report, not a
   subset for coverage) is not gated. A /soft/ gate (warn, not raise) was chosen
   because the conditioning is a legitimate diagnostic -- the blessed =jadj=
   p-value contrast acknowledges it -- and warn-loudly matches the repo's #138
   "diagnose loudly" pattern. Guard: =TestSelectionConditionalGate=.
2. *=coupling_id= provenance. RESOLVED (#171): keep explicit; reject
   callable-derivation; add a coupled-arms factory.* Auto-deriving the token from
   the =dgp= callable in =replicate= is unsound: the ladder passes a /fresh
   lambda per arm/, so =id(dgp)= differs across coupled arms (false-refuse ->
   forces =assert_coupled=, losing the guard), while =__qualname__= / bytecode
   collide across /different/ DGPs sharing a lambda body (false-accept -> the B1
   hole #167 closed); closure-hashing is fragile (unhashable JAX arrays) and
   blind to branching inside the DGP. A function's semantic identity is not
   computable -- the witness must come from /construction/. So =replicate_coupled=
   (=driver.py=, #171) builds the arms together over one =(dgp, key)= and stamps
   a fresh per-call shared token; sound by construction, and the per-arm
   =coupling_id= stays the low-level primitive.
3. *=h_boundary_readout= carrier. RESOLVED: track as issue #173.* It reconstructs
   the /mask draw stream/ -- a different carrier (the missingness-field law), not
   a records query -- so it can't be expressed via =given= / =crn_pair=. Tracked
   as a v2.1 mask-field-law carrier in the =EstimatorLaw= family (issue #173),
   not built here.
4. *Ledger path/format. RESOLVED: Org at =.coder/ledger.org=.* Converted from the
   skill-default Markdown to match the workspace's Org-mode prose convention
   (ASCII-only; =verbatim= for identifiers; description lists in place of the
   Sec. 5 table). =.coder/= is git-tracked (not gitignored).

** 7.4 -- Invariants / landmines

1. *=result.V_X= == =V_star_hat=, not raw \(V\).* =estimator.py:1101= labels the
   /regularised/ \(V^*\). The block-inverse identity test and the binding-ridge
   guard both depend on this; if =V_X= ever changes to carry raw \(V\), the
   diagnostic's metric silently changes.
2. *Block-inverse identity is regime-bounded (the #178 Finding-2 boundary).*
   \(\mathcal{I}_{b\cdot c}^{-1} = (\Sigma_\theta)_{bb}\) holds EXACTLY only under
   efficient weighting at a non-binding ridge (where \(\Sigma_\theta = B^{-1}\)).
   Under =Identity= / =Fixed(V0)= or a binding ridge, \(\Sigma_\theta\) is the
   #133 weighting-aware sandwich \(B^+ (G' \Lambda V \Lambda G) B^+\)
   (=estimator.py:858-861=), NOT \(B^{-1}\). The concentration ranking /
   =.weakest= stay valid (the efficient metric is deliberate); the reciprocal tie
   does not. Hedged in the =identification.py= docstring; the
   =test_block_inverse_identity_against_sigma_theta= fixture stays in the CU /
   \(\tau \approx 0\) regime by design.
3. *=min_eigenvalue= can be slightly negative from roundoff* on a near-singular
   Schur complement (pseudo-inverse keeps PSD only up to rounding). =.weakest= /
   =< threshold= are robust; do not assert =>= 0= exactly.
4. *Profiling cost.* One full inner =estimate= per grid point; the closure
   captures the fixed value, so each retraces -- =jax.clear_caches()= per grid
   point (CLAUDE.md per-call-leak rule). Estimate-running tests are
   =@pytest.mark.slow=.

*** Definitions and invariants

- =m= is the vector of moment means and =G= differentiates those same means.
  =V= is their covariance in mean units; =score_covariance[j]= is
  =Cov(G[:,j],m)=, with shape =(p,M,M)= and no symmetry assumption.
- The supplied symmetric PD =V= is used for both correction and whitening,
  matching the high-level =V== override.
  This entry point does not recompute a ridge or change the supplied metric.
- Common-N long-run covariance inputs must first be converted to mean
  covariance units on BOTH covariance tensors.
  Unequal observability uses the existing pair-specific normalisation
  (Section 3), never a scalar-N criterion multiplier.
- =p_id = p - gauge_nullspace_dim= controls both the SVD projection and dofs:
  =(p_id, M-p_id, M)=.
  Keep the count rule; numerical rank thresholding is a separate policy.
- Shape and static-integer errors refuse before tracing arithmetic.
  Invalid numerical inputs must propagate with a named event flag (#140);
  the expected =p_S= NaN when its dof is zero is not an input failure.
  The additive =KStatisticResult.invalid_input= is a Boolean array on the
  validated array path and defaults to =None= on the unchanged legacy path.
  Traced predicates check finiteness, pair-scale-relative symmetry and PD;
  invalid inputs/intermediates are excluded from the SVD and flagged.
  The symmetry tolerance uses the product of marginal standard deviations
  for each moment pair: a global maximum can hide order-one correlation
  asymmetry under unequal units.
  Apply machine epsilon before multiplying the scales to avoid overflow.
- Preserve high-level dispatch, =V=/=L= overrides, the explicit legacy
  strong-ID fallback, and the concentrated-nuisance subvector reference.
