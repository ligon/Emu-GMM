#+TITLE: emu-gmm tutorial --- querying the =EstimatorLaw=
#+OPTIONS: toc:2 num:nil
#+SUBTITLE: One query algebra over the law of your estimator, at two epistemic grades

Every estimator in this framework constructs a random variable:
\(\hat\theta = T(X_1, \dots, X_N)\) is a measurable map, and its *law* is
the pushforward of the sampling distribution of the data through \(T\).
The =EstimatorLaw= interface (#144) makes that law a first-class object
you query --- instead of hand-rolling means, quantiles, coverage rates,
and paired contrasts over stacks of estimates.

This is a tutorial: one worked thread, every code block runnable
top-to-bottom. For wiring a model into =estimate()= in the first place,
read =docs/howto.org=; for the design rationale, see =docs/design.org=
§"Prospective sketch: =EstimatorLaw=" and the module docstring of
=src/emu_gmm/law.py=. All printed output below is the actual output of
the assembled blocks (floating-point values shown at numpy's default
print precision).

* The one-paragraph mental model

An =EstimatorLaw= answers questions about the distribution of a
statistic: =mean()=, =cov()=, =se()=, =quantile(q)=, =prob(pred)=,
=sample(key, n)=, =given(event)=. Every query takes an optional
*functional* =f= of the parameter components that projects the law onto
a derived quantity of interest (=f=None= is the identity on the flat
parameter vector). Two concrete *grades* implement the one algebra, and
the grade fixes the epistemic status of every answer:

| Grade            | Carrier                                             | Get one from                                    |
|------------------+------------------------------------------------------+-------------------------------------------------|
| =AsymptoticLaw=  | \(\mathcal N(\hat\theta, \Sigma_\theta)\), first order | one =estimate()= result (delta-method queries)  |
| =EmpiricalLaw=   | a stack of draws (MC records, bootstrap draws)       | =replicate(...)= records, or a bare draws array |

When to reach for which:

- =AsymptoticLaw= :: you have *one fit on real data* and want standard
  errors, Gaussian CIs, and delta-method SEs of derived functionals ---
  cheap, closed-form, first-order. It is the law-shaped view of what
  =result.standard_errors= / =result.functional_se= already compute.
- =EmpiricalLaw= :: you have *many draws of the statistic*: a Monte
  Carlo study under a known DGP (calibration questions --- coverage,
  size, bias), a refit bootstrap's =theta_boot=, or a wild bootstrap's
  =J_boot= (the empirical law of \(Q\)). Conditioning on diagnostic
  events and CRN-coupled contrasts live *only* at this grade.

Where a query has no closed form at the asymptotic grade (=given=,
=prob=), the implementation *refuses rather than approximates* --- that
is the grade semantics working as intended, and you will see it below.

* The worked model: an over-identified mean

A compact fixture we keep for the whole tutorial: \(N = 200\)
observations of two noisy views of one location, \(M = 3\) moment
conditions for \(K = 2\) parameters (over-identified, =J_dof= = 1),
continuously-updated weighting.

#+begin_src python
import jax
import jax.numpy as jnp
import jax_dataclasses as jdc
import numpy as np

from emu_gmm import (
    ContinuouslyUpdated,
    EmpiricalMeasure,
    IIDCovariance,
    estimate,
)

N, M = 200, 3
MU_TRUE, SIGMA2_TRUE = 1.0, 0.49


@jdc.pytree_dataclass
class Params:
    mu: jax.Array
    sigma2: jax.Array


def psi(x, theta):
    # x: one observation, shape (2,).  M = 3 moments for K = 2 parameters:
    # two location moments and one variance moment (over-identified, J_dof = 1).
    return jnp.array(
        [
            x[0] - theta.mu,
            x[1] - theta.mu,
            (x[0] - theta.mu) ** 2 - theta.sigma2,
        ]
    )


def dgp(key):
    k0, k1 = jax.random.split(key)
    x0 = MU_TRUE + jnp.sqrt(SIGMA2_TRUE) * jax.random.normal(k0, (N,))
    x1 = MU_TRUE + jax.random.normal(k1, (N,))
    x = jnp.column_stack([x0, x1])
    return EmpiricalMeasure(x=x, mask=jnp.ones((N, M)), weights=jnp.ones(N))


theta_init = Params(mu=jnp.asarray(0.5), sigma2=jnp.asarray(1.0))
measure = dgp(jax.random.PRNGKey(0))
result = estimate(
    psi,
    measure,
    covariance=IIDCovariance(),
    weighting=ContinuouslyUpdated(),
    theta_init=theta_init,
)
print("theta_hat:", float(result.theta_hat.mu), float(result.theta_hat.sigma2))
print("J:", float(result.J_stat), "dof:", result.J_dof)
#+end_src

The =dgp(key) -> Measure= hook is written for the Monte Carlo section

* Grade 1: the asymptotic law of one fit

Wrap the =EstimationResult= and the Gaussian
\(\mathcal N(\hat\theta, \Sigma_\theta)\) becomes queryable. Nothing is
recomputed: =mean= is the point estimate, =cov= *is* =Sigma_theta=,
=se= is =result.standard_errors=, and =quantile= is the exact Gaussian
marginal =mean + z_q * se=.

#+begin_src python
from emu_gmm import AsymptoticLaw

asy = AsymptoticLaw(result)
print(asy)
print("mean:    ", asy.mean())           # the point estimate, flat
print("se:      ", asy.se())             # sqrt(diag(Sigma_theta))
print("cov:\n", asy.cov())               # Sigma_theta itself, (K, K)
print("q(0.975):", asy.quantile(0.975))  # Gaussian marginal: mean + z_q * se

draws = asy.sample(jax.random.PRNGKey(1), 1000)
print("sample:  ", draws.shape, draws.mean(axis=0))
#+end_src

* Grade 2: the empirical law from =replicate()=

The empirical grade is carried by a stack of draws. The canonical
source is the =emu_gmm.studies= Monte Carlo driver: build the estimator
*once* with =build_estimator= (the factory path --- compiled once, no
per-call cache leak), then =replicate= it over fresh datasets.

Two contracts worth knowing before you run one:

- *CRN keys.* Replicate =r= always sees =jax.random.fold_in(key, r)=.
  Any single replicate is reproducible from =(key, r)= alone, and two
  arms run with the same =(dgp, key)= see *identical draws* rep-for-rep
  --- the Common Random Numbers contract the coupling section builds on.
- *Per-draw custom statistics* (the #183 =statistics== channel). Each
  extractor =fn(result, measure) -> scalar= is called once per replicate
  with that rep's fitted result and the measure the harness drew, and
  the values stack into =MCRecords.extra=. This is how you record a
  statistic the =FitRecord= schema doesn't carry (an
  identification-robust K p-value at a null, a condition number, ...)
  without hand-rolling a replication loop.

#+begin_src python
from emu_gmm import build_estimator
from emu_gmm.studies import replicate

run = build_estimator(
    psi,
    measure=measure,  # the template measure (labels, ridge anchor)
    covariance=IIDCovariance(),
    weighting=ContinuouslyUpdated(),
    parameters=theta_init,
)

mc = replicate(
    run,
    dgp,
    n_reps=100,
    key=jax.random.PRNGKey(42),
    theta_init=theta_init,
    statistics={
        "kappa_V": lambda result, measure: result.diagnostics.kappa_V,
    },
)
print(mc.n_reps, "reps;", mc.n_converged, "converged,", mc.n_excluded, "excluded")
print(mc.to_pandas()[["theta_mu", "se_mu", "J_pvalue", "kappa_V"]].head(3))
#+end_src

Same algebra, different grade: these are now finite-sample Monte Carlo
answers under the *known* DGP, not first-order Gaussian ones. The
queries delegate to the same =Bootstrap*= functionals the adaptive
bootstrap uses (=BootstrapSE=, =BootstrapQuantile=, ...) --- the law is
a router, not a re-implementation.

Two things =EmpiricalLaw= can be built from besides =MCRecords=: a bare
draws array via =EmpiricalLaw.from_draws(values)= --- e.g. a wild
bootstrap's =J_boot=, giving the empirical law of \(Q\), whose
=law.pvalue(J_observed)= is the cluster-wild over-identification
p-value --- and a refit bootstrap's =theta_boot=. Raw-draws laws answer
=mean/se/quantile/pvalue/prob=, but not the records-only queries
(summarizers, =couple=), and =given= only if you pass =events== masks.

* Functional queries and component selection

Every query takes =f=, a functional of the *components tuple* ---
exactly what =result.components()= returns, one ambient array per
parameter leaf in field order. =f= is how you select a component or
push the law through a derived quantity; the grade decides the method:

- asymptotic grade :: the delta method (=functional_se=), Jacobian at
  \(\hat\theta\);
- empirical grade :: =f= applied *per draw*, then the empirical
  functionals.

#+begin_src python
mu_hat = lambda comps: comps[0]            # component selection
sd_hat = lambda comps: jnp.sqrt(comps[1])  # a derived functional

print("asy  se(mu):   ", asy.se(mu_hat))
print("asy  se(sigma):", asy.se(sd_hat))   # delta method

emp_f = EmpiricalLaw.from_records_with_template(mc, result)
print("emp  se(mu):   ", emp_f.se(mu_hat))
print("emp  se(sigma):", emp_f.se(sd_hat))  # per-draw application
#+end_src

#+begin_example
asy  se(mu):    [0.04142749]
asy  se(sigma): [0.03693847]
emp  se(mu):    [0.03946607]
emp  se(sigma): [0.03736037]
#+end_example

The two grades agree here to within Monte Carlo noise --- that
cross-grade comparison (delta-method SE vs MC SD) is itself the classic
calibration check, and the summarizer section computes it as a ratio.

One wiring note: an empirical law needs to know how to *unflatten* each
draw's flat vector back into components before it can apply =f= ---
that is the =component_shapes= argument, and
=from_records_with_template(mc, result)= reads it off a representative
fit so you don't spell it out.

*Manifold fits (the gauge note).* For a =PSDFixedRank= factor
\(\Gamma = A A^\top\), the raw =theta_flat= columns are
gauge-arbitrary: never reduce them directly. The shipped gauge-invariant
functionals and conveniences do this correctly at *both* grades ---
=law.eigenvalue_se(rank)= / =law.gamma_se()= on either law, or the
explicit =eigenvalue_functional(rank)= / =gamma_functional()= from
=emu_gmm.law= passed as =f= (asymptotic: the gauge-invariant delta
method; empirical: applied per draw, =theta_flat[r] -> A -> Gamma ->
eigvalsh=). This tutorial's scalar model has no gauge; for a worked
manifold example see =tests/test_law.py= (=TestGaugeAwareCodomain=) and
=tests/test_persistence.py= (=TestManifoldRoundTrip=).

* Conditioning: =given(E)= and the exclude-but-count discipline

An empirical law over MC records carries the per-rep diagnostic event
flags (=converged=, =binding_ridge=, =sigma_meat_indefinite= --- the
=FLAG_FIELDS=), so the *joint* law of \((\hat\theta, \text{events})\) is
queryable. =given(event)= returns another =EstimatorLaw= on the
sub-population where the event holds; =event_share= reports the
selection's size with *both* denominators (all reps, and converged
reps), so a conditional answer is never silently dressed as a marginal
one. =event= is a flag name or any predicate
=FitRecord -> (n_reps,) bool=.

#+begin_src python
share = emp.event_share("converged")
print(share)

low_p = emp.given(lambda rec: np.asarray(rec.J_pvalue) < 0.5)
high_p = emp.given(lambda rec: np.asarray(rec.J_pvalue) < 0.5, negate=True)
print("split:", low_p.n_draws, "+", high_p.n_draws, "=", emp.n_draws)
print("mean(mu | p<0.5): ", low_p.mean()[0])
print("mean(mu | p>=0.5):", high_p.mean()[0])
print("conditioned:", low_p.conditioned)
#+end_src

The =given(E)= / =given(E, negate=True)= pair is an exact partition of
the draws. A conditioned law is a sub-population: it answers the whole
query algebra, but it can never be CRN-coupled (masking destroys the
rep-index alignment --- see the next section) and it cannot be persisted
(save the whole sweep, re-condition on reload).

Conditioning on an *estimator-internal* flag (=binding_ridge=,
=sigma_meat_indefinite=) is a special hazard: the event is a function of
the same data as \(\hat\theta\) and its SE, so any coverage / size
summary over the subset is *selection-conditional, not nominal*. The
law warns --- pass =acknowledge_conditional=True= once you have read the
warning as agreeing to treat the result as a within-selection
diagnostic:

* Summarizers: calibration read off the law

The layer-2 study summaries are methods on a records-backed
=EmpiricalLaw= --- they route through the =emu_gmm.studies= functions
(=bias_sd=, =coverage=, =size_power=, =tau_binding=, =j_calibration=)
with numerically identical results, and each one excludes-but-counts
non-converged reps and NaN SEs (the =n_used= / =n_valid_se= fields).

* Coupling: CRN-paired contrasts, verified before zipped

The joint law of \((T_A(X), T_B(X))\) is *not* determined by the
marginals; it exists in the records only because the =replicate= CRN
contract aligned draws across arms. So the coupling constructor
*verifies* the shared probability space before zipping --- =n_reps=,
=param_names=, the master =key=, and a =coupling_id= witness --- and
refuses otherwise. Master-key equality alone is necessary but *not
sufficient* (it cannot witness the DGP's internal split scheme), which
is why two independently-built arms refuse even at the same key:

#+begin_src python
from emu_gmm import Identity, couple
from emu_gmm.studies import replicate_coupled

run_id = build_estimator(
    psi,
    measure=measure,
    covariance=IIDCovariance(),
    weighting=Identity(),  # arm B: identity weighting, same estimand
    parameters=theta_init,
)

solo_cu = replicate(run, dgp, n_reps=40, key=jax.random.PRNGKey(7), theta_init=theta_init)
solo_id = replicate(run_id, dgp, n_reps=40, key=jax.random.PRNGKey(7), theta_init=theta_init)
try:
    couple(EmpiricalLaw.from_records(solo_cu), EmpiricalLaw.from_records(solo_id))
except ValueError as e:
    print("couple():", str(e)[:63], "...")
#+end_src

    th = np.asarray(rec.theta_flat)[:, 0]

    return (np.abs(th - MU_TRUE) <= 1.96 * se).astype(float)

The returned =CoupledRecords= exposes the paired-contrast queries:
=paired_diff= / =mean_paired_diff= (the =where= subpopulation is
*mandatory by design* --- the contrast denominator must be explicit) and
=flips=, the directional gain/lose counts of a 0/1 indicator between
arms. Here the two weightings agree draw-for-draw on this easy model ---
the point is the machinery, which is exactly what a covariance-strategy
or weighting comparison study runs at scale. Remember the ordering rule:
*pair first, then condition* a paired contrast via
=flips(..., where=event_mask)= --- a =given=-conditioned law refuses to
couple.

Two footnotes from this run. First, the =Identity=-weighted arm warns
that =J_pvalue= is NaN by design (#188: no \(\chi^2_{M-K}\) reference
under an inefficient weighting) --- =J_stat= itself remains the numeric
criterion value, which is why the contrast above uses \(\hat\mu\) and
the coverage indicator rather than J p-values. Second, arms typically
differ in strategy (weighting, covariance), not in the model: same
draws, scored differently, is the CRN use case.

* Persistence: estimate once, query many

Both grades persist to an *inert, versioned* artifact --- a single
=.npz= carrying arrays plus a JSON manifest, *not* a pickle: no class
references, no model code, reloadable under a future emu. Save with
=law.save(path)= (or =save_law(law, path)=), reload with =load_law=.

#+begin_src python
import tempfile

from emu_gmm import FactorySpec, load_law, load_law_state, save_law

outdir = Path(tempfile.mkdtemp())

emp_path = outdir / "mean_model_empirical.npz"
emp.save(emp_path)  # equivalently: save_law(emp, emp_path)

np.testing.assert_array_equal(

state = load_law_state(emp_path)  # cheap inspection, no law rebuild
print("grade:", state.grade, "| n_reps:", state.n_reps, "| extra:", sorted(state.extra_arrays))

The records-backed round-trip preserves the full =FitRecord= stack plus
the =MCRecords= provenance (master =key=, =coupling_id=), so a reloaded
law still answers =given= / =couple= / =size_power= / =se= --- and the
#183 per-draw custom statistics (=MCRecords.extra=; our =kappa_V=
column) ride the artifact and come back exactly. =load_law_state= is
the cheap inspection path: the typed =LawState= record, without
rebuilding a queryable law. A *conditioned* law refuses to save ---
persist the whole sweep and re-condition on reload.

The asymptotic grade reloads *moments-backed*: the component arrays and
=Sigma_theta= alone, with no live =EstimationResult= behind it --- but
=se= / =functional_se= / =eigenvalue_se= / =gamma_se= route through the
same delta-method machinery and match the live law bit-for-bit. Pass a
=FactorySpec= to record the estimator configuration that is part of
\(T\)'s identity (weighting, covariance, your own payload in =extra=):

* Caveats that bite

*=EmpiricalLaw.se()= is not =sqrt(diag(cov()))= under coordinate-specific
NaNs.* The two queries filter differently, by design: =se()= (and
=mean= / =quantile=) filters *per column* --- each coordinate uses every
draw finite in *that* coordinate --- while =cov()= (and =prob= /
=sample=) keeps only rows finite in *all* coordinates, because a
covariance needs complete rows. When one coordinate of a functional
fails on some draws (a log or sqrt of a boundary-crossing quantity, an
SE that NaN'd on an indefinite sandwich meat), the shared coordinates
are computed from *different* draw counts:

#+begin_src python
def mu_and_loggap(comps):
    # log(mu_hat - 1) is NaN whenever mu_hat <= 1: a coordinate-specific
    # failure that leaves the first coordinate perfectly finite.
    return jnp.stack([comps[0], jnp.log(comps[0] - MU_TRUE)])


se_cols = emp_f.se(mu_and_loggap)
se_from_cov = np.sqrt(np.diag(emp_f.cov(mu_and_loggap)))
print("se() per column:        ", se_cols)
print("sqrt(diag(cov())):      ", se_from_cov)
print("first coordinates equal?", bool(np.isclose(se_cols[0], se_from_cov[0])))
#+end_src

#+begin_example
se() per column:         [0.03946607 1.15430711]
sqrt(diag(cov())):       [0.02148056 1.15430711]
first coordinates equal? False
#+end_example

The first coordinate (\(\hat\mu\), finite in all 100 draws) has its SE
computed from all 100 draws by =se()= but from only the ~50
all-coordinates-finite rows by =cov()=. Neither number is wrong; they
answer different questions (a marginal SE vs the diagonal of a
complete-rows covariance). If you report both, say which filter you
used --- and treat a large gap between them as the diagnostic it is:
some coordinate of your functional is failing on a non-trivial share of
draws.

Smaller ones, for the road:

- *Exclude-but-count is everywhere.* =from_draws= keeps non-finite rows
  in =n_draws= but out of every functional; summarizers surface
  =n_used= / =n_excluded= / =n_valid_se=. If a denominator surprises
  you, look for the counted exclusions before suspecting the statistic.
- *A negative =cov= diagonal propagates as NaN in =se()=* (both grades)
  rather than a complex number --- same convention as
  =result.standard_errors=.
- *Raw-draws laws are deliberately limited*: no summarizers, no
  =couple=, and =given= only with explicit =events== masks.
